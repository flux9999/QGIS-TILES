# 長崎市オフライン地図タイル (.mbtiles)

このリポジトリには
、⻑崎県⻑崎市全域をカバーするオフライン地図タイルデータが含まれて
います。

## 含まれるデータ
1. 地理院地図 (標準地図): 
nagasaki_gsi_std.mbtiles (ズーム 0-15)
2. OpenStreetMap (OSM): 
nagasaki_osm.mbtiles (ズーム 0-15)

## QGISでの利⽤⽅法
1. QGISを起動します。
2. ブラウザパネル（通常は左側）から「ベクトルタイル」または「XYZ Tiles」ではなく、直
接ファイルをドラッグ＆ドロップするか、以下の⼿順で追加します。

   •メニューの レイヤ > レイヤを追加 >ラスタレイヤを追加... を選択。
 
   •ダウンロードした .mbtiles ファイルを選択して開く。

3. レイヤパネルに追加されたレイヤを右クリックし、「レイヤの領域にズーム」を選択すると、範囲が表⽰されます。
